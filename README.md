# Calculadora-simple-en-Python
Desarrollado por:
- Adalberto Ruiz Chavez

Este proyecto consiste en una calculadora básica desarrollada en Python utilizando PySide6 para crear una interfaz gráfica.
La aplicación permite introducir dos números y realizar las operaciones matemáticas básicas:

- Suma.
- Resta.
- Multiplicación.
- División.

También cuenta con validación de datos para evitar entradas incorrectas y muestra un mensaje de error cuando se intenta realizar una división entre cero.

Tecnologías utilizada:
- Python 3
- PySide6
- Qt
